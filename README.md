# ibrahimahmed237.github.io

Personal portfolio of Ibrahim Ahmed, software engineer (full stack, backend and applied AI).

Live at **https://ibrahimahmed237.github.io**

In English and Arabic (`?lang=ar`, right to left). A static site with no build step: `index.html` holds the page template, `assets/content.js` the words in both languages, `assets/app.js` the interactions, `assets/motion.js` the motion on scroll, `assets/oss/` the open-source diagrams in light and dark, and `assets/runtime.js` a small renderer that keeps the page in sync using [morphdom](https://github.com/patrick-steele-idem/morphdom) (MIT).

Run it locally with any static server, for example:

```bash
python3 -m http.server 8000
```
