# ibrahimahmed237.github.io

Personal portfolio of Ibrahim Ahmed, software engineer (full stack, backend and applied AI).

Live at **https://ibrahimahmed237.github.io**

A static site with no build step: `index.html` holds the page template, `assets/app.js` the data and interactions, and `assets/runtime.js` a small renderer that keeps the page in sync using [morphdom](https://github.com/patrick-steele-idem/morphdom) (MIT).

Run it locally with any static server, for example:

```bash
python3 -m http.server 8000
```
